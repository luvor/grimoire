# Grimoire — Инструкции для агентов

## Что это

Grimoire (グリモワール) — статический сайт-платформа для публикации лонгридов на GitHub Pages. Каждая статья — глубокое исследование идеи с фактами, визуализацией, схемами и красивой вёрсткой.

**URL**: https://luvor.github.io/grimoire/
**Репозиторий**: `luvor/grimoire`

## Структура

```
/
├── index.html                    # Главная страница с карточками статей
├── assets/css/                   # main.css (темы, карточки), article.css (типографика)
├── assets/js/                    # main.js (тема, анимации), article.js (TOC, прогресс)
├── articles/{slug}/              # Каждая статья в своей папке (index.html, cover.svg, images/)
├── scripts/                      # generate-image.py, censor-faces.py, generate-article-photos.py
└── templates/article.html        # Шаблон для новых статей
```

## Дизайн-система

**Цвета:** `--color-accent: #d4a574` (тёмная), `--color-accent: #8b5e3c` (светлая). Все через `var(--color-*)`.

**Шрифты:** Cormorant Garamond (заголовки), Source Serif 4 (текст), JetBrains Mono (код), Noto Serif JP (японский).

**Принципы:**
- Контент-первый — текст читаемый и красивый
- Визуально насыщенный — SVG-схемы, фото, диаграммы
- Тёмная и светлая тема
- Адаптивная вёрстка (мобильный)
- Без фреймворков — чистый HTML/CSS/JS

## Требования к качеству

- Минимум 1500 слов
- Минимум 3 визуализации (SVG, изображения, диаграммы)
- Все факты проверены, обязательна секция источников
- Текст живой, не сухой — каждая статья как мини-расследование
- AI-фото: лица скрыты (hidden via prompt + auto-head), WebP ≤200 КБ
